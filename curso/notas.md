Requisitos - Claude que lo haga, una especie de checklist

- Ordenador con Windows 11, macOS 13+ o Linux actualizado, mínimo 16 GB de RAM recomendados, CPU de 4 núcleos y al menos 20 GB de espacio libre para repositorios, contenedores, dependencias y herramientas de desarrollo.
- IDE moderno como Visual Studio Code o cualquier IDE de JetBrains; Claude Code dispone de integración oficial con VS Code y JetBrains, además de uso en terminal, web y escritorio.
- Acceso corporativo a Claude Team o Claude Enterprise; en Team existen actualmente asientos Standard y Premium con mínimo de cinco miembros, y en Enterprise el acceso a Claude Code se incluye junto con Claude web/desktop/mobile, pero el uso se factura adicionalmente por consumo a tarifas API estándar.
- Para equipos que no trabajen aún con plan corporativo, acceso autorizado a Claude Code mediante el plan que la organización haya aprobado, teniendo en cuenta que la disponibilidad y el gobierno de funciones varían según el plan activo.

- Git instalado y acceso a repositorios corporativos con permisos de lectura, escritura, creación de ramas y gestión de pull requests.
- Acceso a terminal local, Docker Desktop o motor de contenedores equivalente para prácticas de entornos, scripts y dockerización.
- Acceso a servicios de CI/CD como GitHub Actions o GitLab si se van a realizar prácticas de automatización y revisión continua, ya que Claude Code ofrece presencia oficial en esos flujos.

- Permisos para configurar archivos de proyecto como `.claude/settings.json`, `.claude/settings.local.json`, `.claude/agents/`, `.mcp.json`, `CLAUDE.md` y Skills compartidas cuando el repositorio esté gobernado por el equipo técnico.
- Conocimientos previos de desarrollo de software, Git, terminal, testing y arquitectura básica de aplicaciones; el curso no está orientado a principiantes absolutos en programación.
- Para contenidos avanzados de SDK y agentes programables, Python o TypeScript instalados y permisos para ejecutar dependencias del Claude Agent SDK, que es el nombre actual del antiguo Claude Code SDK.
